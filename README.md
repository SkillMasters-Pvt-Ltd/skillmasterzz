# Skill Masters Digital Studio

Extract the whole ZIP, then open index.html in Edge, Chrome, Firefox or Safari. No installations or build commands are required.

The homepage, project filters, service details, featured work and student offer run locally. The enquiry form opens a WhatsApp draft addressed to the studio. The visitor reviews the draft and presses Send in WhatsApp. An internet connection is required for WhatsApp and social links.

Edit index.html for page copy and contact links, style.css for appearance, catalog.js for services and projects, and app.js for interaction settings and the WhatsApp destination.
